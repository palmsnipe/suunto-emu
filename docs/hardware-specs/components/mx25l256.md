# Macronix MX25L256-class serial NOR

## Public specification

The relevant Macronix family is a 256-Mbit (32-MiB) 3-V serial NOR family. The
official product catalog describes the MX25xxx serial-NOR families and their
single/dual/quad serial interfaces. The exact `MX25L25645G` datasheet URL is
recorded in [`sources.tsv`](../sources.tsv); Macronix currently serves that
endpoint inconsistently, so the PDF is linked rather than cached.

- [Macronix serial NOR product catalog](https://www.macronix.com/en-us/products/NOR-Flash/Serial-NOR-Flash/Pages/default.aspx)
- [Macronix technical documentation](https://www.macronix.com/en-us/support/technical-documentation)
- [MX25L25645G datasheet URL](https://www.macronix.com/Lists/Datasheet/Attachments/9113/MX25L25645G%2C%203V%2C%20256Mb%2C%20v1.2.pdf)

## Sapporo evidence

`E-SAP-FLASH-001` pins a 32-MiB geometry, JEDEC identity `20 BB 19`, and
observed commands including:

- `0x9f` JEDEC identification;
- `0x0c` read with a 24-bit address;
- `0x06` write-enable;
- `0x21` 4-KiB erase;
- `0x12` page program;
- `0x70` status and `0x85` observed response behavior.

The emulator's backing data is the OTA resource component already loaded at
`0x14000000`. That is a resource-backed compatibility boundary, not a claim
that the OTA contains a complete physical flash image.

## Cross-watch warning

Ulsan observes a different Macronix-compatible identity, `c2 25 39`, through
MSPI1 and uses a recovered tail at `0x18040000`. It must not be silently
treated as Sapporo's `20 BB 19` device.

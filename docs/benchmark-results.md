# CPU Benchmark Results

Generated by `tools/bench_cpu.c`.

Workloads execute synthetic Thumb programs through the
interpreter's `semu_cpu_step` and measure wall-clock time
for a fixed instruction budget. Lower time is better.

Each measurement is the best of 5 trials (resetting CPU state
between trials) to minimize host noise (thermal, scheduling).
Baseline and optimized use the identical methodology.

Host: Apple Silicon, macOS 26.5, clang -O2

## Optimizations Applied

1. **Pending-exception fast-path** (`src/cpu/armv7m/cpu.c`):
   Skip `armv7m_pending_exception()` when `pending_source_count == 0`.
   The count is maintained in lockstep with all pending-source arrays
   (verified by snapshot validation). This eliminates a cross-TU call
   and a priority scan on every instruction in the common no-IRQ case.

2. **IT-state conditional computation** (`src/cpu/armv7m/cpu.c`):
   Only compute `it_flags` (XPSR read) and `preserve_it_flags` (function
   call) when actually inside an IT block (`old_itstate != 0`).

3. **Inline hot-path helpers** (`src/cpu/armv7m/armv7m_internal.h`):
   Converted `armv7m_reg`, `armv7m_set_sp`, `armv7m_set_nz`,
   `armv7m_add`, `armv7m_sign_extend`, `armv7m_condition_passed`,
   `armv7m_scs_address`, `armv7m_request_bus_fault`, and
   `armv7m_fetch16` from cross-TU calls to `static inline` in the
   internal header. This eliminates 3–5 function calls per instruction
   on the common ALU path.

# 625 — Deterministic Malformed-Input Corpus

**Status:** blocked
**Phase:** 6
**Dependencies:** 620

## Goal

Exercise every parser and decoder with committed deterministic malformed corpora
and convert discovered failures into narrow regressions.

## Execution Budget

Two model-days; corpus generators and focused tests, not broad refactoring.

## Required Reading

All manifest, CPU, Nema, replay, and snapshot parser entry points; their bounds
contracts and existing negative tests.

## Current Baseline

Manifests and CPU unsupported instructions have focused negatives, but there is
no shared bounded malformed corpus or coverage inventory.

## Allowed Files

`tests/**`, `fixtures/synthetic/malformed/**`, `tools/generate_malformed_*`, and
narrow source fixes only when accompanied by a failing regression.

## Frozen Interfaces

Corpus seeds and mutation enumeration are deterministic and checked in or
generated by a checked-in C99/shell tool. Every invocation is operation-bounded.

## Evidence Inputs

No authentic data; use synthetic minimum-valid inputs for each format.

## Implementation

Enumerate truncation, length overflow, reserved bits, duplicate/unknown fields,
bad state, and boundary addresses. Record which entry point owns each seed.

## Tests and Commands

`make test TEST_FILTER=malformed_corpus` selects the corpus test and exits 0
under normal and sanitizer builds. Run `make check-lines && make check && make
sanitize` twice and compare the corpus summary hash.

## Acceptance

No hang, sanitizer report, partial mutation, or nondeterministic diagnostic;
every fixed defect has a named focused regression.

## Forbidden Scope

No nondeterministic fuzzing, downloaded corpus, sanitizer suppression, or
expected-output weakening.

## Handoff

Report seed count, case count, summary hash, defects/regressions, and gaps.
